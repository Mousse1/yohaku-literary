# 余白。 v6.2.1 — フォーム補足文の削除漏れ修正

前回配布したv6.2では、入力欄の `placeholder`（未入力時の欄内例文）は削除済みでしたが、入力欄の外側に補足説明文が残っていました。

## この版で修正した部分

- 基本情報フォーム下のグループ階層説明の段落を削除
- 同じ場所の「著作の作者と、サイト掲載用の入力・整理・要約を担当した方を区別できます。」の段落を削除
- グループ紹介欄のすぐ下にあった補足文を削除
- `index.html` に `<meta name="yohaku-version" content="v6.2.1"/>` を追加して、反映されたか判定しやすくしました

これらは本文の入力欄と周辺の見た目の修正のみです。ジャンル、入力／構成、階層グループ、数式、文字数上限、改訂審査、データベースは変更しません。

## GitHub → Cloudflare Workers の反映手順

1. GitHubで今使っているブランチと、Cloudflareの `Settings → Build → Root directory` を確認します。
2. そのディレクトリの `src/main.jsx` と `index.html` を、このZIPにある同名のファイルで更新します。`package.json` と `index.html` は同じディレクトリの直下に置きます。
3. GitHubでコミットし、Cloudflareの最新の本番デプロイがそのコミットを使用していることを確認します。
4. ブラウザのシークレットモードでサイトを開き、入力欄と付近の説明が消えたか確認します。
5. F12のConsoleで `document.querySelector('meta[name="yohaku-version"]')?.content` を実行すると `v6.2.1` が表示されます。表示されなければ、旧版が配信されています。

SupabaseのSQL・APIキー・環境変数は変更不要です。

## 重要

v6.2のコードには「例：スピノザ／自作ならご自身の筆名」の文字列が存在しません。更新後も**その文字列が入力欄内に残る場合**は、削除漏れではなく、古いデプロイが公開中である可能性が高いです。
