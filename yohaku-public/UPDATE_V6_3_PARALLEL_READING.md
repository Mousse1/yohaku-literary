# 余白。v6.3 — 複数パネル読書機能

## 追加機能

- 「並べて読む」をクリックし、本文と注釈を並べて表示
- パネルは最大4つ（本文・注釈・参考文献／解説）
- 各パネルで別作品を選択（親グループ・章・節も公開済みであれば選択可能）
- 各パネルは独立スクロール。文字サイズは一括変更（12–26px）
- スマートフォンでは読みやすい縦並び表示
- 改訂・投稿・審査・作品URLは維持

## Cloudflare Workersへの更新手順

1. 既存のGitHubリポジトリをバックアップしてください。
2. このフォルダ内の `src/main.jsx`、`src/style.css`、新規 `src/ParallelReader.jsx`、`index.html` を、GitHubの**同じ位置**に反映してください。その他のファイルはv6.2.1を引き継いでいます。
3. Cloudflare Workers の **Root directory** が `package.json` / `index.html` のあるディレクトリを指すか確認します。
4. デプロイし、公開サイトで「並べて読む」を開いて、本文・注釈を横に表示できるか確認します。
5. ある作品の詳細画面の「本文と注釈を並べて読む」からも試します。別作品・階層下の作品を選択し、各スクロールが独立しているか確認してください。
6. シークレットモードで未承認作品・未承認注釈を取得できないことを確認してください。

Cloudflareのビルドコマンドは `npm run build`、デプロイコマンドは `npx wrangler deploy`（従来の構成を維持）。

## Supabase

**追加SQLは不要**です。現行の `works`・`notes`・`work_references` を参照するだけで、DB定義も書き込み処理も変更していません。
従来の `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` をそのまま使います。

## 補足

- パネルの構成は画面を開いている間だけ保持され、共有URLには含まれません。個々の作品URL `/works/:id` は引き続き共有できます。
- 利用できる作品選択一覧は、画面で取得できた公開済み作品（現在は最大1,000件の階層インデックス）です。作品の固定URLから開いた作品は、一覧に含まれなくても並列読書を開始できます。
- 注釈は承認済みのもののみ表示し、現行の上限100件まで読み込みます。
- スマートフォンでは横並びでなく縦積みになります。
- 本番ビルド・Supabase実接続テストはこの作業環境では未確認です。運用前に実環境で確認してください。
