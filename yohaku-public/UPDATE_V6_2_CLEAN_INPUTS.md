# 余白。v6.2 — 入力欄の例文・プレースホルダー削除

v6.1をベースに、未入力時に入力欄内へ表示していた例文・案内文を削除しました。

## 変更点

- 作品名、作者（原著者）、入力／構成、主題、作品紹介、本文、問い、先行作品、新規性、参考文献、改訂説明の入力欄にあるプレースホルダーを削除しました。
- グループ説明欄、注釈欄、作品検索欄も同様に空欄表示へ統一しました。
- 作者・入力／構成の説明段落にあった具体的な氏名例も削除しました。
- 項目名、必須入力判定、文字数上限、作品階層、公開審査、共有URL、改訂履歴、Supabaseデータ構造には変更がありません。

## 更新方法

1. GitHubの既存コードをバックアップします。
2. このZIPにある `yohaku-public/src/main.jsx` を、リポジトリ内の同じパスのファイルと置き換えます。
3. GitHubへコミットします。Cloudflare Workersに連携されていれば再ビルド・再デプロイが実行されます。
4. 新規投稿画面・編集画面で、入力欄が空白のまま表示されることを確認してください。

**Supabaseへの追加SQLや環境変数の変更は不要です。**
