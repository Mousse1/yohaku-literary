# 余白。v7.7 — 注釈印から対応する参考文献を「並べて読む」

このZIPは **v7.6を元に変更したフロントエンドのみの差分更新** です。
既存のGitHubリポジトリの `yohaku-public/` に同じ相対パスで差し替えてください。
Cloudflare Workerの `worker/`、`wrangler.jsonc`、`.env`、Supabaseの設定やデータベースは **上書き・変更しません**。

## できるようになること

- 作品本文中の `*1`・`**1` を押すと、ページ内の脚注へジャンプするのではなく、**「並べて読む」** で本文パネルと該当の参考文献パネルを表示します。
- 編集時「書式・数式」→「注釈番号 **」を押すと、本文へ **`**` の2文字だけ**挿入。表示時には `**` を登場順に *1、*2…と自動採番します。Markdownの `**太字**` は従来どおり太字として扱います。
- 参考文献編集に「対応する注釈番号（任意）」を追加。例：本文の1番目の `**` には `1`、2番目には `2` を設定して保存します。既存の `*1` にも `1` を設定します。
- 対応する参考文献の「書名」「関連の理由」「URL」を隣のパネルに表示。URLがあればプレビューを同じパネルに試み、埋め込み不可なら新しいタブで表示できます（外部サイトのX-Frame-Options/CSPは回避できません）。
- 下位作品の本文にも対応し、同じ「並べて読む」画面から別のマーカーを押して切り替えられます。
- 番号が設定されていない文献は勝手に関連付けしません。既存文献は編集画面で番号を付与してください。

## 設定・互換性

- **Supabaseの追加SQLは不要**。既存の参考文献 `title` カラムに `【*1】 書名` のように番号を保持する方式です。番号情報は公開JSON APIやTXT/MDの書名にも含まれます（見せるための出典番号であり、秘密情報ではありません）。
- 既存のURL、参考文献登録数20件、投稿・保存・改訂審査ワークフローはそのままです。
- 以前の v7.6 から変化したのはこのZIPに含むファイルだけです。**これまで修正した `worker/publicWorksApi.js` の `redirect:'manual'` 等の変更は維持してください。**
- 閲覧環境によっては外部リンクのiframe表示がブロックされるため、「新しいタブで開く」を併設しています。
- `index.html` の版表記を v7.7 に更新しています。

## 反映手順

1. ZIP内の `yohaku-public/src/` 以下のファイルを、GitHubの同じパスへ**上書き**し、新しい `src/referenceAnnotations.js` も追加。
2. `yohaku-public/index.html` を上書き。
3. `tests/` 以下のファイルも任意でコピー。CIを利用する場合はテストも最新版に更新。
4. GitHubにコミットし、Cloudflareで `npm run build` と `npx wrangler deploy` が成功したら公開作品で確認。
5. 投稿済み作品の文献は、作者が作品の編集画面に入り「対応する注釈番号」を入力して保存。番号を持つ本文マーカーを押すと対応文献が開きます。
