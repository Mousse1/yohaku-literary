# 余白。v6 — 親作品・章・節・階層目次

v5 の分類・原著者／入力者の区別、v4 の Markdown／KaTeX 数式と文字サイズ、v3 の個別作品URL、v2 の承認・改訂履歴の上に、**作品内作品**を実装します。

実際に公開中の既存サイトを更新する場合は、先に `UPDATE_V6_GUIDE.md` を読んでください。DBの追加マイグレーションは `supabase/migrations/20261030_nested_works.sql` です。既存の `.env`・Supabase URL/Keyは変えません。

「目次グループ」には本文を持たせずに各作品を収録でき、通常の本文の上限20万文字は変わりません。各子作品はそれ自身の個別URLを持ちます。
